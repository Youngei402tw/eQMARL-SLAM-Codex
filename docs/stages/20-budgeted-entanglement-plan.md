# Stage 20 — budgeted-entanglement MARL prospectus

## Preflight

- **Question:** Can a learned controller allocate a consumable Bell-pair budget across a changing interaction graph more efficiently than static, random, or myopic allocation?
- **Smallest falsifier:** a fixed-seed request-family screen in which exact classical enumeration and optimized Bell policies show no heterogeneous positive gaps, leaving nothing meaningful to allocate.
- **Deliverables:** literature/novelty screen, sequential benchmark contract, exact controls, held-out design, compute limits, inference rules, and claim boundaries.
- **Exit gate:** the full prospective plan is remotely published before reportable implementation results.
- **Failure gate:** inability to define exact classical controls, independent quantum upper bounds, or a genuine sequential budget decision cancels later performance claims.

## Opportunity screen

The study explicitly excludes active SLAM and CHSH. A bounded public search found static CHSH/MIMO entanglement-assisted MARL code and a recent entanglement-allocation sample-complexity paper, but no retrieved work combining dynamic graph matching, consumable Bell pairs, decentralized MARL reward, and a learned horizon-aware allocator. The plan therefore avoids priority language and requires a broader human review before submission.

A non-reportable fixed-seed falsification screen generated twelve `3 x 3` private-context binary-action constraint types. Exact enumeration and independent continuous Bell-policy optimization found heterogeneous quantum-classical gaps: some zero, others approximately 0.004–0.075. This is the needed allocation structure: useful and useless requests coexist. These scratch outcomes select the research question only; Stage 21 will regenerate committed development/validation/final manifests and certify every value independently.
